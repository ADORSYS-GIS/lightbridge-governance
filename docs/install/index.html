governance-auth

OAuth2 credential helper for pointing Claude Code, Codex and VS Code at this org's governed AI gateway.

Install

curl --proto '=https' --tlsv1.2 -fsSL https://adorsys-gis.github.io/lightbridge-governance/install.sh | sh

Read it first if you like — install.sh.txt is the same file served as plain text. Piping anything into sh deserves that much.

Uninstall

curl --proto '=https' --tlsv1.2 -fsSL https://adorsys-gis.github.io/lightbridge-governance/uninstall.sh | sh

Removes the binary, stops and removes the Copilot drain schedule, revokes your session at the identity provider, and clears local state. Add --purge to also remove ~/.config/governance-auth and the managed block from your shell rc files.

Run governance-auth configure with no --gateway-url or --otel-endpoint before uninstalling if you want the keys it wrote into Claude Code, Codex and VS Code retracted automatically. The uninstaller cannot do it afterwards — the binary that owns those keys is gone by then.

What it does, and does not do

  • Verifies the published .sha256 before installing. A missing or mismatched checksum is a refusal, not a warning.
  • Picks one of six published targets from uname. On Linux it installs the musl build by default — the glibc builds link against 2.39 and will not start on Ubuntu 22.04, Debian 12, RHEL 9 or Amazon Linux 2023.
  • Never edits your shell rc files. It prints the export PATH=… line for you to place yourself. governance-auth configure writes its own managed block into those files, and two independent writers to one .zshrc is a mess somebody has to untangle by hand.

Freshly cut releases

For a few minutes after a release is published, GitHub already points latest at it while its binaries are still building. The installer notices, falls back to the newest release that actually has your platform's asset, and tells you which one it used. --version never falls back — a pin that quietly installed something else would defeat the purpose.

Pinning

--version pins the binary. It does not pin this script, which is always served from main. A reproducible image build should vendor a copy of install.sh rather than curl it.
